# Day 16 — Excel Reporting Automation

An `ExcelReportBuilder` class that turns a raw sales CSV into a
polished, 3-sheet Excel workbook — the kind of file a manager can
open and immediately use, with no manual formatting.

---

## What gets built

| Sheet | Contents |
|---|---|
| **Summary** | KPI dashboard: total revenue, total orders, average order value, top region — styled as large, bold figures |
| **Raw Data** | The full dataset with a colored/styled header row, frozen header (`freeze_panes`), and Excel's native AutoFilter dropdowns |
| **By Category** | A revenue-by-category summary table plus a **native embedded Excel bar chart** (not a static image — it's a real chart object, editable in Excel) |

---

## Key concepts used

- Programmatic Excel generation with `openpyxl` (`Workbook`, sheets,
  cell styling)
- Cell formatting: fills (`PatternFill`), fonts (`Font`), alignment
- Auto-sized columns based on content length
- Frozen panes and AutoFilter for a usable, scrollable data sheet
- Native Excel charts built from cell `Reference`s (`BarChart`,
  `Reference`, `add_data`, `set_categories`) — not a pasted image
- Clean separation: each sheet is built by its own testable method,
  orchestrated by a single `build()` call

---

## Dataset

`data/sales_data.csv` (400 orders) is generated by `generate_data.py`:

```bash
python generate_data.py
```

## How to run

```bash
python main.py
```

This saves the report to `output/sales_report.xlsx`.

## How to test

```bash
pip install -r ../../requirements.txt
pytest test_main.py
```
