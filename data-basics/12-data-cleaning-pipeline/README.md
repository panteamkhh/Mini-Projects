# Day 12 — Data Cleaning Pipeline

A `DataCleaner` class that turns a deliberately messy customer-orders
CSV into an analysis-ready `DataFrame` — and reports exactly what it
fixed along the way. In real jobs, cleaning is most of the work
before any analysis happens; this project treats that seriously
instead of skipping straight to a tidy CSV.

---

## Problems in the raw data (and how they're fixed)

| Problem | Example | Fix |
|---|---|---|
| Exact duplicate rows | same order appears twice | `drop_duplicates()` |
| Inconsistent text casing/whitespace | `" north "`, `"SOUTH"`, `"east"` | strip + Title Case |
| Dates in 3 different formats | `2024-01-05`, `01/15/2024`, `5-Feb-2024` | `pd.to_datetime(..., format="mixed")` |
| Currency written inconsistently | `"$120.50"`, `"1,000.00"`, `" 99.99 "` | strip `$`/commas/whitespace, cast to float |
| Invalid quantities | `-2`, `0`, `"N/A"` | coerce to numeric, drop non-positive/unparsable |
| Missing values | empty `customer_name`, `amount`, etc. | `dropna` on critical columns, after logging counts |

Every step is a separate, independently testable static method
(`standardize_text`, `parse_messy_dates`, `parse_messy_amount`,
`parse_quantity`), orchestrated by `clean()`, which also builds a
row-by-row-dropped report — so nothing gets silently deleted.

---

## Key concepts used

- Handling missing data (`isna`, `dropna`, `notna`)
- Removing duplicates (`drop_duplicates`)
- Parsing inconsistent date strings (`pd.to_datetime`, `format="mixed"`)
- Cleaning and converting string-encoded numbers (`str.replace`,
  `pd.to_numeric`, `errors="coerce"`)
- String normalization (`str.strip`, `str.title`)
- Building a transparent, testable, step-by-step cleaning pipeline
  instead of one opaque function

---

## Dataset

`data/raw_customer_orders.csv` is generated by `generate_data.py`
with every issue above injected deterministically (fixed seed), so
the "before" state is reproducible:

```bash
python generate_data.py
```

## How to run

```bash
python main.py
```

This prints a before/after cleaning report and writes
`data/clean_customer_orders.csv`.

## How to test

```bash
pip install -r ../../requirements.txt
pytest test_main.py
```
