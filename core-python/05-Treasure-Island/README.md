# 🏝️ Treasure Island Game

A simple text-based adventure game built with Python where your choices decide your fate.  
Find the treasure… or face Game Over 💀

---

## 🎮 How the Game Works

You start on a mysterious island and must make the right decisions step by step:

1. Choose direction at the crossroad (`left` or `right`)
2. Decide whether to `wait` or `swim`
3. Pick a door (`red`, `yellow`, or `blue`)

Only one path leads to the treasure 🏆

---

## 🧠 Game Logic

- Wrong choices lead to different Game Over scenarios
- Only the **yellow door after waiting** leads to victory
- All inputs are case-insensitive
